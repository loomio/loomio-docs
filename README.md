# Loomio documentation has moved

The Loomio help documentation is now maintained in the main
[`loomio/loomio`](https://github.com/loomio/loomio/tree/master/docs)
repository under `docs/`.

The published documentation is available at
[www.loomio.com/docs](https://www.loomio.com/docs/). Requests to the former
`help.loomio.com` site redirect to the corresponding canonical documentation
URLs.

Please make documentation changes and open pull requests in
[`loomio/loomio`](https://github.com/loomio/loomio). This repository is no
longer used to build or deploy the help site and is retained as an archive of
its previous source and history.
